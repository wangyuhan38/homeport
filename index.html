让 Claude、Google 只看到
你的一个住宅 IP

填上住宅代理，选好设备，复制粘贴到你的代理软件里。敏感网站固定走住宅 IP，其他网站照常走机场。

✅ 开始前，先确认这 3 件事
  • 有机场，而且现在能正常翻墙。homeport 会借机场的节点当跳板，自动挑最快的那个，任何机场、任何地区的节点都行。
  • 买好了一条静态住宅代理（HTTP 或 SOCKS5），手里有：地址、端口、用户名、密码。
  • 装好了代理软件，并且机场订阅已经导入：Mac 用 Clash Party / Clash Verge Rev / 小火箭；Windows 用 Clash Verge Rev / Clash Party；iPhone、iPad 用小火箭；安卓用 FlClash。

1填写住宅代理信息

照着服务商后台，把下面四项填上。

用 Webshare 的：先在后台代理列表上方把 Connection Method 切到 Backbone Connection（最稳定；别选 Rotating Proxy Endpoint，那个 IP 如果有问题，官方会自动换，换了你要去后台手动获取重新配置才行）。
然后照列表填：地址填 Proxy Address（如 p.webshare.io），不是 Assigned IP；Assigned IP 是出口 IP，留着最后核对。
后台写的是哪个就选哪个；不确定先选 HTTP，不通再换 SOCKS5。
填好四项后，下面的按钮就能用了。

2选哪些网站走住宅 IP

不懂就保持默认，直接看第 3 步。

修改 / 添加网站

高级：也可以写整条规则，如 DOMAIN-KEYWORD,openai、IP-CIDR,1.2.3.0/24，策略会自动补上。

3选设备和软件，照着做

已按你的设备自动选好，不对就手动点。

Clash Party

开始前：Clash Party 已装好，机场订阅已导入，现在能正常翻墙。

  1. 复制脚本
  2. 新建覆写

    左侧 覆写 → 右上角 ＋ → 新建 JavaScript。把编辑框里原有的内容全部删掉，粘贴，保存。

    下载了文件的话，也可以在 ＋ 里选「导入」，选 homeport.js。

  3. 挂到机场订阅上

    左侧 订阅管理 → 机场订阅卡片右上角 ⋯›编辑信息 → 覆写 里勾选 homeport → 保存。

    这一步最容易漏：不勾选，等于没装。
  4. 重启生效

    左侧 内核设置 → 点重启（旋转箭头）。首页代理模式选 规则，系统代理 保持打开。

    想让 Claude 桌面版、Claude Code 这类不认系统代理的软件也走：再打开 虚拟网卡（TUN），第一次会要求授权，点允许。

🪜 跳板 = 你在机场里选的节点。平时怎么选节点照旧，选哪个，住宅代理就经过哪个，网站看到的始终是住宅 IP。只是别选 🏠住宅出口-勿选。

v2rayN

      
v2rayN 做不到这种分流。它的路由规则只能选「代理 / 直连 / 拦截」三种，没法把 Claude 单独指到住宅节点、再让住宅节点经过机场跳板。

      
    
        
  1. 装 Clash Verge Rev
          
    去 GitHub 搜 clash-verge-rev，在 Releases 里下载 Windows 安装包（文件名带 x64-setup.exe）安装。
    2. 
        
  2. 把同一个机场订阅导进去
          
    在 v2rayN 的 订阅分组›订阅分组设置 里复制订阅地址；到 Clash Verge Rev 的 订阅 页粘贴 → 导入。
    
          
    一般机场后台也能直接复制「Clash 订阅」链接，用那个更好。
    3. 
        
  3. 退出 v2rayN
          
    两个软件同时开会抢系统代理，用 Clash Verge Rev 时把 v2rayN 退出。
    4. 
        
  4. 按 Clash Verge Rev 的步骤做
          
    5.

小火箭 Shadowrocket （Mac 版，M 芯片 Mac 才能装）
